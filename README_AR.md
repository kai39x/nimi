# حزمة NIMI لـ Claude Code

## طريقة الاستخدام
1. فك الضغط في مجلد جديد للمشروع، مثلاً: `D:\Projects\nimi`.
2. افتح Claude Code **على جهازك** (مو السحابة)، داخل المجلد نفسه.
3. اختر الموديل والجهد:
   - `/model fable`
   - `/effort xhigh` للمرحلة 0 والمرحلة 1.
   - بعدها `/effort high` لباقي المراحل.
4. الصق محتوى `PROMPT.md` كأول رسالة، أو اكتب: `اقرأ PROMPT.md وابدأ`.
5. بعد كل مرحلة جرّب البرنامج بنفسك، وإذا كل شي تمام قل له يكمل.

## وش فيها
- `PROMPT.md`: البرومبت.
- `design/DESIGN_SPEC.md`: كل قرارات التصميم المعتمدة.
- `design/boards/`: صور كل اللوحات بالترتيب.
- `design/character/`: الشخصية بكل حالاتها.
  - `nimi-reference.html`: افتحه بالمتصفح وتشوفها تتحرك.
  - كود الرسم والحركة.
  - ملفات SVG.
- `design/icons/`:
  - أيقونة البرنامج: SVG وPNG وICO.
  - أيقونة منطقة الإشعارات.
  - ٦٨ أيقونة للواجهة.
- `design/brand/`: الشعار المكتوب.
- `design/sounds/`: الـ ١٤ صوت.
- `design/tokens/`: الألوان والأحجام والحركة، جاهزة للـ CSS.
